# Changelog

## 1.0.0 — Template release
First public release of the VentStudio Lite HoReCa template.

- Menu system with per-item visibility + stock
- Cart, checkout (delivery/collection), Stripe payment
- Opening hours + homepage OPEN/CLOSED switch
- Pre-order items with lead time (works while closed)
- Invoices (HTML + PDF), bulk ZIP, credit notes on refund
- Branded transactional emails incl. ready-to-collect, kitchen & courier
- Optional allergen page + checkout allergy notice
- Admin: dashboard, menu, orders, hours, emails, invoices, users, docs + tour
- Flat-file storage by default, optional MySQL with migration + graceful fallback
